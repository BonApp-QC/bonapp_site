# Site vitrine BonApp!

Le site public de [bon-app.info](https://bon-app.info) — une seule page
statique, autonome (logo en data URI, aucune dépendance externe).

- **`index.html`** — tout le site : contenu, styles, interactions.
- **`CNAME`** — domaine personnalisé GitHub Pages.

## Déploiement

GitHub Pages sert la branche `main` à la racine. Chaque commit sur `main`
redéploie automatiquement (workflow « pages build and deployment »).

Mettre à jour : branche `<type>/<slug>` → PR → merge sur `main`.
